This repository contains my first dynamic web page created using React. It serves as an introductory project to explore component-based architecture and web deployment.

## 🚀 Live Demo

Check out the live deployment here: [My First React Project](https://my-first-react-project-w9z9.vercel.app/)

*   **React.js**
*   **JavaScript**
*   **CSS**
*   **HTML**

## ⚙️ Getting Started

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Spandan2106/My-first-React-Project.git](https://github.com/Spandan2106/My-first-React-Project.git)
   ```
2.  Navigate to the project directory:

```Bash
cd My-first-React-Project/my-react-app
```
3. Install dependencies:

```Bash
npm install
```
4. Start the development server:

```Bash
npm start
```
```(Note: If the project was initialized with Vite, use npm run dev instead).```
